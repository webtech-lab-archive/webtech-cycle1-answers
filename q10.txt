Q10. Design and develop a static webpage for a Fitness Centre using HTML and CSS. The webpage should contain the fitness centre
name and tagline, navigation menu, About section, fitness programs, membership plans, trainer information, facilities and a
membership registration link. Use headings, paragraphs, images, lists, tables or cards, hyperlinks, sections and footer. Apply CSS Grid
and Flexbox along with background images, box-shadow, border-radius to create an attractive webpage. [50 Marks]
