Q2. Design and develop a static webpage for an Online Learning Platform using HTML and CSS. The webpage should include a
header, navigation menu, hero section containing the course title and description, an Enroll Now button, at least three course cards
containing course name, duration, level and fee, instructor information and a footer. Use headings, paragraphs, images, hyperlinks,
buttons, sections, articles and lists. Apply CSS properties including background, color, font properties, margin, padding, border-radius,
box-shadow, Flexbox to create an attractive layout. [50 Marks]
