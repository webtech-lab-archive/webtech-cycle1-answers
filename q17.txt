Question 1 Template 1 - DOM Button Events
Q1. Develop an HTML page containing a heading and paragraph. Write a JavaScript program to change the heading and
paragraph content dynamically when a button is clicked using DOM methods.
index.html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>DOM Demo</title>
<style>
body{font-family:Arial,sans-serif;background:#eaf2f8;text-align:center;margin:30px}
.box{background:#fff;max-width:460px;margin:auto;padding:20px;border-radius:10px;box-shadow:0 2px 8px rgba(0,0,0,.25)}
input,textarea,select{padding:8px;margin:6px;border:1px solid #888;border-radius:5px;width:85%}
button{background:#2874a6;color:#fff;border:0;padding:9px 18px;margin:5px;border-radius:5px;cursor:pointer}
.err{color:red}.ok{color:green}
table{width:100%;border-collapse:collapse;margin-top:10px}
th,td{border:1px solid #999;padding:6px}th{background:#2874a6;color:#fff}
</style>
</head>
<body>
<div class="box"><h1 id="head">Welcome</h1>
<p id="para">This is the original paragraph.</p>
<button onclick="change()">Change Content</button></div>
<script>
function change() {
  document.getElementById("head").innerHTML = "Heading Changed!";
  document.getElementById("para").textContent = "The paragraph was updated using DOM methods.";
}
</script>
</body>
</html>
