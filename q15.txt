Q15. Design and develop a static webpage for a Digital Library or E-Learning Portal using HTML5 and CSS3. The webpage should
contain the portal name, navigation bar, welcome section, search box, resource categories, resource cards, recently added resources,
author information, membership section, contact information and footer. Use headings, paragraphs, images, lists, hyperlinks, forms,
input fields, buttons, sections and articles. Apply CSS Grid and Flexbox along with box-shadow, border-radius, background properties,
font properties, padding, margins, hover and :focus pseudo-classes. [50 Marks]
