Question 8 Template 1 - Institution Page
Q8. Design and develop a static webpage for a College Sports Club using HTML and CSS. The webpage should contain the club
name and logo, navigation menu, About the Club section, sports offered using a list, upcoming sports events, player or member
information using a table, achievements, a registration link and contact details. Use headings, paragraphs, images, lists, tables,
hyperlinks, sections and footer. Apply CSS properties such as Flexbox, background-color, color, font styling, borders, padding, margin,
border-radius, box-shadow. [50 Marks]
