Q9. Design and develop a static webpage for a College Technical Symposium using HTML5 and CSS3. The webpage should contain
the event title and tagline, event banner, date, time and venue, event description, a list of technical events, an event schedule using a
table and a registration form containing Name, Email, Phone Number, Department, Gender, Event Selection and Submit button. Use
headings, paragraphs, images, tables, <form>, <input>, radio buttons, checkboxes, <select> and buttons. Apply CSS for form fields,
tables, buttons, borders, padding, margins, border-radius and Flexbox. [50 Marks]
