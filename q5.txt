Question 5 Template 1 - Institution Page
Q5. Design and develop a static webpage for a Hospital using HTML and CSS. The webpage should contain the hospital name and
logo, navigation menu, About Hospital section, list of medical departments, doctor details in a table, hospital facilities, emergency
contact information, an appointment link or button and a footer. Use HTML5 semantic elements, headings, paragraphs, images, lists,
tables and hyperlinks. Apply CSS properties such as background-color, color, font-size, padding, margin, border, border-radius, boxshadow, Flexbox. [50 Marks]
