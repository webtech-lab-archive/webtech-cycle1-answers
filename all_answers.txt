Q1. Design and develop a static webpage for a College Department using HTML5 and CSS3. The webpage should contain a header
with the college and department name, a navigation menu with Home, About, Programs, Faculty and Contact links, an About
Department section, Programs Offered using an unordered list, Faculty Details using a table, a department image and a footer. Apply
CSS properties such as background-color, color, font-family, font-size, text-align, margin, padding, border, border-radius and Flexbox
for page layout. [50 Marks]

Answer (index.html - images saved in the same folder):
<!DOCTYPE html>

<head>

<meta name="viewport" content="width=device-width, initial-scale=1.0">

header h1{margin:0;font-size:28px}

nav a{color:#fff;text-decoration:none;font-size:16px}
.wrap{display:flex;gap:15px;padding:10px 15px}
section{flex:1;background:#fff;border:1px solid #ccc;border-radius:8px;padding:15px}
h2{color:#1a5276;margin-top:0}
table{width:100%;border-collapse:collapse}
th,td{border:1px solid #999;padding:6px;text-align:left}
th{background:#1a5276;color:#fff}
img{width:100%;border-radius:8px}
.btn{background:#1a5276;color:#fff;padding:8px 16px;border-radius:5px;text-decoration:none}
