Web Technology Cycle 1 - CMD curl text files

Upload all_answers.txt and q1.txt ... q16.txt to a public GitHub repository.
Then use the GitHub Raw URL for each file, for example:
  curl https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/q1.txt
  curl https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/all_answers.txt

The files contain text extracted from the supplied PDF. Review line wrapping before copying HTML into an editor.
The original PDF contains images/screenshots; plain text output cannot display those images.
