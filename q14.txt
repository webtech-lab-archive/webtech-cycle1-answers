Q14. Design and develop a static webpage for a College Placement Cell using HTML and CSS. The webpage should contain the
Placement Cell name, navigation menu, Placement Cell overview, training programs, recruiting companies represented using cards,
placement statistics using a table, student achievements, upcoming placement drives, contact information and footer. Use headings,
paragraphs, images, lists, tables, hyperlinks, sections and articles. Apply CSS Grid and Flexbox along with card styling, box-shadow,
border-radius, background properties, transitions and hover effects. [50 Marks]
