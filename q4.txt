Q4. Design and develop a static Personal Portfolio webpage for a student or software developer using HTML and CSS. The webpage
should contain the person's name, profile image, professional title, About Me section, technical skills, educational qualifications,
projects, achievements, contact information and social media links. Use appropriate headings, paragraphs, images, ordered or
unordered lists, hyperlinks, sections and footer. Apply CSS Grid and Flexbox along with properties such as background-color, fontfamily, padding, margin, border-radius, box-shadow to design the webpage. [50 Marks]
