Question 2 Template 1 - DOM Button Events
Q2. Create a web page with three buttons labelled Red, Green and Blue. Write JavaScript code to change the background
color of the webpage based on the selected button.
index.html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Background Colour</title>
<style>
body{font-family:Arial,sans-serif;background:#eaf2f8;text-align:center;margin:30px}
.box{background:#fff;max-width:460px;margin:auto;padding:20px;border-radius:10px;box-shadow:0 2px 8px rgba(0,0,0,.25)}
input,textarea,select{padding:8px;margin:6px;border:1px solid #888;border-radius:5px;width:85%}
button{background:#2874a6;color:#fff;border:0;padding:9px 18px;margin:5px;border-radius:5px;cursor:pointer}
.err{color:red}.ok{color:green}
table{width:100%;border-collapse:collapse;margin-top:10px}
th,td{border:1px solid #999;padding:6px}th{background:#2874a6;color:#fff}
</style>
</head>
<body>
<div class="box"><h2>Choose Background Colour</h2>
<button style="background:red" onclick="setColor('red')">Red</button>
<button style="background:green" onclick="setColor('green')">Green</button>
<button style="background:blue" onclick="setColor('blue')">Blue</button></div>
<script>
function setColor(c) {
  document.body.style.backgroundColor = c;
}
</script>
</body>
</html>
